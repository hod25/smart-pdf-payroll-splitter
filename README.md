# Smart PDF Payroll Splitter 🤖✂️

אפליקציית ווב (Streamlit) לפיצול קובץ PDF של תלושי שכר מרובי-עמודים לקבצים נפרדים —
קובץ אחד לכל עובד — עם זיהוי שם אוטומטי ואפשרות תיקון ידני.

## תכונות עיקריות

- **זיהוי שם חכם** — חילוץ מבוסס-קואורדינטות שמאתר את שם העובד מימין לתווית `מחלקה:`,
  כולל תיקון קידוד הגופן (`ð` ← `נ`).
- **ממשק היברידי (Smart + Interactive)** — הניחוש האוטומטי מסומן מראש לכל עמוד,
  והמשתמש יכול לתקן ידנית דרך תיבת בחירה (`selectbox`) עם כל שורות העמוד.
- **פרטיות מלאה** — כל העיבוד מתבצע **בזיכרון בלבד** (`io.BytesIO`). שום קובץ
  לא נכתב או נשמר על דיסק השרת.
- **הורדה כ-ZIP** — כל הדפים המפוצלים נארזים לקובץ ZIP יחיד להורדה.
- **שמות קבצים** — בפורמט `{תאריך} {שם}.pdf`, כשהתאריך נלקח משם הקובץ המקורי.
- **ממשק RTL** — עברית מיושרת לימין.

## הפעלה מקומית

```bash
pip install -r requirements.txt
streamlit run app.py
```

האפליקציה תיפתח בדפדפן בכתובת http://localhost:8501.

## פריסה ב-Render (Web Service)

- **Build Command:**
  ```bash
  pip install -r requirements.txt
  ```
- **Start Command:**
  ```bash
  streamlit run app.py --server.port $PORT --server.address 0.0.0.0
  ```

## מבנה הפרויקט

| קובץ | תיאור |
| --- | --- |
| `app.py` | אפליקציית ה-Streamlit |
| `requirements.txt` | תלויות: `streamlit`, `pypdf` |
| `.gitignore` | מונע העלאת קבצי זבל ותלושים (`*.pdf`, `*.zip`, `*.xlsx`) |

## אבטחת מידע

מכיוון שמדובר בתלושי שכר, האפליקציה לא שומרת אף קובץ על השרת — כל הקבצים
מעובדים בזיכרון RAM בלבד ונמחקים בסיום הבקשה.
